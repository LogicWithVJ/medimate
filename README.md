# MediMate - AI-Powered Health & Medicine Adherence Platform

MediMate helps patients and caregivers stay on top of medication schedules by
extracting prescription information (OCR + LLM), generating reminder
schedules, and tracking adherence over time.

## Status
Under active development - built step by step.

## Setup
1. python -m venv venv
2. venv\Scripts\activate (Windows)
3. pip install -r requirements.txt
4. Copy .env.example to .env and fill in real values.

## Tech Stack
Flask, SQLAlchemy, SQLite, OpenCV, Tesseract OCR, Hugging Face Transformers,
APScheduler, Twilio, Bootstrap, Docker.
